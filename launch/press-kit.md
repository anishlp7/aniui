## One-paragraph pitch

**AniUI** is the first React Native component library built for the
agent-native era. A copy-paste component library in the shadcn/ui tradition —
150 components, 15 pre-built screens, MIT-licensed, iOS + Android — with the
full modern AI-agent surface: an MCP server, a shadcn-spec registry, an
`llms-full.txt`, and an auto-discovered Agent Skill file. Works first-call
with Cursor, Claude Code, Windsurf, and v0 without any custom integration.

## Stats

- **150** components (across Tier 1 zero-dep, Tier 2 reanimated, Tier 3
  gesture/primitives, Tier 4 Skia)
- **15** pre-built blocks (login, signup, chat, pricing, onboarding, …)
- **5** Expo SDKs supported (54 → 58)
- **2** styling engines (Uniwind and NativeWind, same API)
- **8** MCP tools
- **1** 818 KB `llms-full.txt` with every component's source
- **0** runtime dependencies on an AniUI package (the CLI is the only published
  thing; everything else is source files the user owns)
